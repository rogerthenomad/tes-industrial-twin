# TES Studio

Interactive 3D review model of the Trinium Energy System.

- **Unit** — modified 40-foot container, four hubs, shared fuel and electrolyte tanks
- **Facility** — eight banks of ten hubs (4 MW example), plus water, power, and operations zones
- **Stack** — representative exploded reactor and fuel-cell plates

DOE view matches the concept layouts. Engineering view adds oxygen support, thermal rejection, water recovery, and the dedicated anolyte loop. Flow overlays trace power, water, fuel, carbon-bearing liquid, oxygen, and coolant.

Illustrative geometry only. Not a fabrication drawing, P&ID, or release of controlled dimensions, recipes, or control logic.

```bash
npm install
npm run dev
```
